## Global Constraints

- Только стандартная библиотека Python в `vmlogs_cli/` и `tests/`; `requires-python = ">=3.9"`. Не использовать синтаксис новее 3.9: `match`, `X | Y` в аннотациях без `from __future__ import annotations`, `str.removeprefix` можно (3.9). В каждом модуле пакета — `from __future__ import annotations`; дженерики — `list[str]`, `dict[str, str]`, `tuple[...]`, `Optional[...]` из `typing`, коллекции — из `collections.abc`.
- В файлах репозитория, сообщениях коммитов, тестовых данных и примерах — никаких имён реальных хостов, кластеров, проектов и компаний. Примеры — `example.com`, `myserver`, `shop`, `api`.
- Сообщения коммитов — одна строка-тема без тела, без `Co-Authored-By` и упоминаний ИИ; формат `<тип>: <суть>` по-русски.
- Ошибки для пользователя — исключение `vmlogs_cli.errors.CliError`, печатаются как `vmlogs-cli: <текст>` в stderr, код выхода 1, без трейсбэка.
- Тексты для пользователя (ошибки, подсказки, справка) — по-русски.
- Формат маркера обрезки — публичный контракт: `… [truncated: N/M chars, get <stream_id>/<time>]`.
- Перед каждым коммитом: `uv run ruff format . && uv run ruff check --fix .`, затем тесты.
- Тесты запускаются из корня репозитория: `uv run python -m unittest discover -s tests -v`.

```python
import json

GOOD = "grafana_session=good"


class FakePlaywright:
    """Вместо playwright-cli. mode: silent — сессия жива без окна; headed — только после окна;
    never — вход так и не случился."""

    def __init__(self, mode, open_fails=False):
        self.mode = mode
        self.open_fails = open_fails
        self.headed = False
        self.calls = []

    def __call__(self, cmd, cwd=None, **kwargs):
        assert cmd[0] == "playwright-cli" and cmd[1] == "-s=vmlogs-cli", cmd
        assert cwd, "playwright-cli должен работать во временном каталоге"
        args = cmd[2:]
        self.calls.append(args)
        if args[0] == "open":
            if self.open_fails:
                return subprocess.CompletedProcess(cmd, 1, "", "net::ERR_NAME_NOT_RESOLVED")
            self.headed = "--headed" in args
            return subprocess.CompletedProcess(cmd, 0, "", "")
        if args[:2] == ["--raw", "run-code"]:
            ready = self.mode == "silent" or (self.mode == "headed" and self.headed)
            return subprocess.CompletedProcess(cmd, 0, json.dumps(GOOD if ready else "") + "\n", "")
        return subprocess.CompletedProcess(cmd, 0, "", "")
```

```python
PW_SESSION = "vmlogs-cli"
SILENT_TIMEOUT = 20
LOGIN_TIMEOUT = 300
FLUSH_TIMEOUT = 45
PW_INSTALL_HINT = "npm install -g @playwright/cli && playwright-cli install-browser"


class BrowserLogin:
    """Вход в Grafana через SSO в настоящем браузере (playwright-cli) с постоянным профилем.

    Порядок: сохранённая сессия или её продление без браузера → браузер без окна (SSO-сессия
    в профиле ещё жива) → окно, где вход проходит человек.
    """

    def __init__(
        self,
        session,
        cfg_dir: Path,
        run=subprocess.run,
        which=shutil.which,
        sleep=time.sleep,
        clock=time.monotonic,
        wall=time.time,
        err=None,
    ):
        self.session = session
        self.profile = cfg_dir / "chrome-profile"
        self.run = run
        self.which = which
        self.sleep = sleep
        self.clock = clock
        self.wall = wall
        self.err = err if err is not None else sys.stderr

    def _say(self, text: str) -> None:
        print(f"vmlogs-cli: {text}", file=self.err)

    def _pw(self, cwd: str, *args: str) -> subprocess.CompletedProcess:
        cmd = ["playwright-cli", f"-s={PW_SESSION}", *args]
        return self.run(cmd, cwd=cwd, capture_output=True, text=True)

    def _open(self, cwd: str, headed: bool) -> None:
        url = self.session.base_url + "/"
        args = ["open", *(["--headed"] if headed else []), "--persistent"]
        proc = self._pw(cwd, *args, "--profile", str(self.profile), url)
        if proc.returncode != 0:
            detail = " ".join((proc.stderr or proc.stdout or "").split())[:300]
            raise CliError(
                f"playwright-cli не открыл {url}: {detail}\n"
                "Проверь VPN и браузер: playwright-cli install-browser"
            )

    def _close(self, cwd: str) -> None:
        self._pw(cwd, "close")

    def _capture(self, cwd: str) -> Optional[str]:
        # context.cookies(url) не открывает страниц и сам подбирает cookie родительских доменов.
        url = json.dumps(self.session.base_url + "/")
        code = (
            f"async page => {{ const cs = await page.context().cookies({url}); "
            "return cs.map(c => c.name + '=' + c.value).join('; '); }"
        )
        proc = self._pw(cwd, "--raw", "run-code", code)
        if proc.returncode != 0:
            return None
        try:
            header = json.loads(proc.stdout.strip())
        except ValueError:
            return None
        # Cookie появляются раньше, чем закончен вход: годится только та, с которой отвечает API.
        if isinstance(header, str) and self.session.valid(header):
            return header
        return None

    def _wait(self, cwd: str, timeout: int) -> Optional[str]:
        deadline = self.clock() + timeout
        while self.clock() < deadline:
            header = self._capture(cwd)
            if header:
                return header
            self.sleep(1)
        return None

    def _wait_profile_flush(self, since: float) -> None:
        # Chrome пишет cookie в профиль раз в ~30 с, а закрытие из playwright-cli теряет
        # несохранённое — и следующий вход снова открыл бы окно.
        self._say(f"сохраняю сессию в профиле браузера (до {FLUSH_TIMEOUT} с) ...")
        databases = (
            self.profile / "Default" / "Cookies",
            self.profile / "Default" / "Network" / "Cookies",
        )
        deadline = self.clock() + FLUSH_TIMEOUT
        while self.clock() < deadline:
            if any(db.exists() and db.stat().st_mtime > since for db in databases):
                return
            self.sleep(1)
        self._say("профиль не записал cookie — в следующий раз, возможно, снова откроется окно")

    def login(self) -> None:
        if self.session.refresh():
            self._say(f"вход в {self.session.base_url} рабочий: сохранённая сессия жива или продлена")
            return
        if not self.which("playwright-cli"):
            raise CliError(f"для входа нужен playwright-cli: {PW_INSTALL_HINT}")
        # playwright-cli складывает служебный каталог .playwright-cli в текущий каталог.
        with tempfile.TemporaryDirectory() as cwd:
            self._close(cwd)
            try:
                self._open(cwd, headed=False)
                header = self._wait(cwd, SILENT_TIMEOUT)
                logged_in_at = None
                if not header:
                    self._close(cwd)
                    minutes = LOGIN_TIMEOUT // 60
                    self._say(
                        f"войди в {self.session.base_url} в открывшемся окне (жду до {minutes} минут) ..."
                    )
                    logged_in_at = self.wall()
                    self._open(cwd, headed=True)
                    header = self._wait(cwd, LOGIN_TIMEOUT)
                    if not header:
                        raise CliError(
                            f"за {minutes} минут вход не завершился — запусти vmlogs-cli login ещё раз"
                        )
                save_secret(self.session.path, header)
                self._say(f"вход сохранён в {self.session.path}")
                if logged_in_at is not None:
                    self._wait_profile_flush(logged_in_at)
            finally:
                self._close(cwd)
```

```python
"""Команды vmlogs-cli: разбор аргументов, выбор транспорта, печать и подсказки."""

from __future__ import annotations

import argparse
import json
import os
import sys
from collections.abc import Mapping
from datetime import datetime, timezone
from typing import Optional

from . import __version__
from .config import Settings, config_dir, load_settings
from .errors import CliError
from .login import BrowserLogin, GrafanaSession, cookie_file
from .output import DEFAULT_HIDE, field_lines, is_hidden, json_line, short_line, sort_records
from .timewin import window
from .transport import DEFAULT_TIMEOUT, DirectTransport, GrafanaTransport, KubectlTransport

EPILOG = """примеры:
  vmlogs-cli check
  vmlogs-cli query 'kubernetes.pod_namespace:=shop error | stats count() c' --since 6h
  vmlogs-cli query 'kubernetes.pod_namespace:=shop error' --since 6h --limit 20
  vmlogs-cli fields 'kubernetes.pod_namespace:=shop'
  vmlogs-cli values 'kubernetes.pod_namespace:=shop' level
  vmlogs-cli get <stream_id>/<time>

профиль: $VMLOGS_ENV, .vmlogs-cli/env вверх от текущего каталога, ~/.config/vmlogs-cli/env
"""


def build_parser() -> argparse.ArgumentParser:
    conn = argparse.ArgumentParser(add_help=False)
    conn.add_argument("--env", help="файл профиля вместо поиска")
    conn.add_argument("--ds", help="датасорс Grafana (имя или uid) вместо VMLOGS_DATASOURCE")
    conn.add_argument(
        "--timeout", type=int, default=DEFAULT_TIMEOUT, help="секунд на запрос (%(default)s)"
    )

    win = argparse.ArgumentParser(add_help=False)
    win.add_argument("--since", default="1h", help="окно назад от сейчас: 15m, 6h, 2d (%(default)s)")
    win.add_argument("--start", help="начало окна: длительность или RFC3339; перебивает --since")
    win.add_argument("--end", help="конец окна: длительность или RFC3339 (по умолчанию — сейчас)")
    win.add_argument("--all-fields", action="store_true", help="не скрывать служебные поля")

    parser = argparse.ArgumentParser(
        prog="vmlogs-cli",
        description="Поиск логов в VictoriaLogs: LogsQL как есть, компактный вывод.",
        epilog=EPILOG,
        formatter_class=argparse.RawDescriptionHelpFormatter,
    )
    parser.add_argument("--version", action="version", version=f"%(prog)s {__version__}")
    sub = parser.add_subparsers(dest="cmd", metavar="<команда>", required=True)

    query = sub.add_parser("query", parents=[conn, win], help="строки логов или результат | stats")
    query.add_argument("logsql")
    query.add_argument("--limit", type=int, default=50, help="максимум строк, последних по времени (%(default)s)")
    query.add_argument("-o", "--output", choices=("short", "json"), default="short")
    query.add_argument(
        "--width",
        type=int,
        default=1000,
        help="обрезать строку (short) или значение (json) длиннее N символов; 0 — не обрезать",
    )
    query.add_argument("--out", help="сырые строки в файл JSONL, на экран — только сводка")

    fields = sub.add_parser("fields", parents=[conn, win], help="имена полей с числом строк")
    fields.add_argument("logsql")

    values = sub.add_parser("values", parents=[conn, win], help="значения поля с числом строк")
    values.add_argument("logsql")
    values.add_argument("field")
    values.add_argument("--limit", type=int, default=50)

    get = sub.add_parser("get", parents=[conn], help="одна запись целиком по ссылке из маркера обрезки")
    get.add_argument("ref", metavar="<stream_id>/<time>")

    sub.add_parser("check", parents=[conn], help="профиль, транспорт и пробный запрос за 5 минут")
    sub.add_parser("login", parents=[conn], help="вход в Grafana (транспорт grafana)")
    sub.add_parser("datasources", parents=[conn], help="датасорсы VictoriaLogs в Grafana")
    return parser


def make_transport(settings: Settings, ds: Optional[str], timeout: int, env: Mapping[str, str]):
    if settings.transport == "direct":
        return DirectTransport(settings.url, timeout)
    if settings.transport == "kubectl":
        return KubectlTransport(
            settings.kube_service,
            settings.kubeconfig,
            settings.kube_context,
            settings.ssh_host,
            timeout,
        )
    session = GrafanaSession(settings.grafana_url, cookie_file(config_dir(env), settings.grafana_url))
    return GrafanaTransport(settings.grafana_url, ds or settings.datasource, session, timeout)


class App:
    def __init__(self, args, settings: Settings, transport, env, now: datetime, out, err):
        self.args = args
        self.settings = settings
        self.transport = transport
        self.env = env
        self.now = now
        self.out = out
        self.err = err
        all_fields = getattr(args, "all_fields", False)
        if all_fields:
            self.hide, self.context = [], None
        else:
            hide = settings.hide_fields
            self.hide = list(DEFAULT_HIDE) if hide is None else hide
            self.context = settings.context_fields

    def _print(self, text: str) -> None:
        print(text, file=self.out)

    def _hint(self, text: str) -> None:
        print(f"[{text}]", file=self.err)

    def _params(self, logsql: str) -> dict[str, str]:
        start, end = window(self.args.since, self.args.start, self.args.end, self.now)
        params = {"query": logsql, "start": start}
        if end:
            params["end"] = end
        return params

    def _json(self, endpoint: str, params: dict[str, str]) -> dict:
        return json.loads("".join(self.transport.fetch(endpoint, params)))

    def query(self) -> None:
        a = self.args
        params = {**self._params(a.logsql), "limit": str(a.limit)}
        lines = self.transport.fetch("query", params)
        if a.out:
            count, names = 0, set()
            with open(a.out, "w", encoding="utf-8") as fh:
                for line in lines:
                    fh.write(line + "\n")
                    names.update(json.loads(line))
                    count += 1
            self._print(f"{count} строк → {a.out}")
            self._print("поля: " + ", ".join(sorted(n for n in names if not is_hidden(n, self.hide))))
        else:
            rows = [json.loads(line) for line in lines]
            count = len(rows)
            if a.output == "short":
                for row in sort_records(rows):
                    self._print(short_line(row, a.width, self.hide, self.context))
            else:
                for row in rows:
                    self._print(json_line(row, a.width, self.hide))
        if count == 0:
            self._hint(
                f"0 строк за окно с {params['start']}. Слова ищутся целиком: bulk не найдёт "
                'bulk_operations — нужен bulk* или ~"bulk"; проверь и окно (--since, --start)'
            )
        elif count >= a.limit:
            self._hint(
                f"показаны последние {a.limit} строк окна — есть ещё: сузь запрос "
                "или посчитай через | stats count()"
            )

    def fields(self) -> None:
        data = self._json("field_names", self._params(self.args.logsql))
        lines, hidden = field_lines(data.get("values", []), self.hide)
        for line in lines:
            self._print(line)
        if hidden:
            self._hint(f"скрыто служебных полей: {hidden} (--all-fields покажет)")

    def values(self) -> None:
        a = self.args
        params = {**self._params(a.logsql), "field": a.field, "limit": str(a.limit)}
        values = self._json("field_values", params).get("values", [])
        for item in values:
            self._print(f"{item['hits']}\t{item['value']}")
        if len(values) >= a.limit:
            self._hint(f"показаны {a.limit} значений — есть ещё: подними --limit")

    def get(self) -> None:
        ref = self.args.ref
        stream_id, sep, moment = ref.partition("/")
        if not (sep and stream_id and moment):
            raise CliError(f"ссылка «{ref}» не похожа на <stream_id>/<time> из маркера обрезки")
        query = f"_stream_id:{stream_id} _time:[{moment}, {moment}]"
        lines = self.transport.fetch("query", {"query": query, "limit": "10"})
        rows = [json.loads(line) for line in lines]
        if not rows:
            raise CliError(f"запись {ref} не найдена — проверь, что ссылка скопирована целиком")
        for row in rows:
            self._print(json.dumps(row, ensure_ascii=False, indent=2))

    def check(self) -> None:
        self._print(f"профиль: {self.settings.path}")
        self._print(f"транспорт: {self.transport.describe()}")
        lines = self.transport.fetch("query", {"query": "_time:5m | stats count() c"})
        rows = [json.loads(line) for line in lines]
        self._print(f"записей за 5 минут: {rows[0].get('c', '0') if rows else '0'}")

    def _grafana(self) -> GrafanaTransport:
        if not isinstance(self.transport, GrafanaTransport):
            raise CliError(
                f"{self.args.cmd} — только для VMLOGS_TRANSPORT=grafana, "
                f"а в {self.settings.path} {self.settings.transport}"
            )
        return self.transport

    def login(self) -> None:
        transport = self._grafana()
        BrowserLogin(transport.session, config_dir(self.env), err=self.err).login()
        self.datasources()

    def datasources(self) -> None:
        for uid, name in self._grafana().datasources():
            self._print(f"{uid}\t{name}")


def run(
    argv: list[str],
    env: Mapping[str, str],
    cwd: str,
    now: Optional[datetime] = None,
    out=None,
    err=None,
) -> int:
    out = sys.stdout if out is None else out
    err = sys.stderr if err is None else err
    args = build_parser().parse_args(argv)
    try:
        settings = load_settings(env, cwd, args.env)
        transport = make_transport(settings, args.ds, args.timeout, env)
        app = App(args, settings, transport, env, now or datetime.now(timezone.utc), out, err)
        getattr(app, args.cmd)()
        return 0
    except CliError as e:
        print(f"vmlogs-cli: {e}", file=err)
        return 1
    except json.JSONDecodeError as e:
        print(f"vmlogs-cli: ответ не похож на JSON VictoriaLogs ({e})", file=err)
        return 1
    except KeyboardInterrupt:
        return 130


def main(argv: Optional[list[str]] = None) -> int:
    try:
        return run(argv if argv is not None else sys.argv[1:], os.environ, os.getcwd())
    except BrokenPipeError:
        # Вывод обрезали (| head): выходим молча, как обычные утилиты.
        devnull = os.open(os.devnull, os.O_WRONLY)
        os.dup2(devnull, sys.stdout.fileno())
        return 0
```

````markdown
# vmlogs-cli

Поиск логов в VictoriaLogs. Запрос — LogsQL как есть, вывод — одна строка на запись.
Команда — `vmlogs-cli`; если её нет в PATH — `bin/vmlogs-cli` в каталоге этого скила.

Куда ходить, задаёт профиль — env-файл без секретов. Первый найденный побеждает:
`$VMLOGS_ENV` → `.vmlogs-cli/env` вверх от текущего каталога → `~/.config/vmlogs-cli/env`.
Профиля нет (`нет профиля`) — попроси пользователя создать его по `README.md` рядом.

## Порядок работы

1. Проверить профиль и доступ:
   ```bash
   vmlogs-cli check
   ```
   Успех — путь к профилю, транспорт и `записей за 5 минут: N`.
2. Посчитать, сколько строк подходит, до того как смотреть сами строки:
   ```bash
   vmlogs-cli query '<фильтр> | stats count() c' --since 1h
   ```
3. Если строк не больше сотни — вывести их:
   ```bash
   vmlogs-cli query '<фильтр>' --since 1h
   ```
   Больше — сузить фильтр или окно, разложить через `| stats by (<поле>) count()`, или
   выгрузить `--limit 5000 --out /tmp/<имя>.jsonl` и разбирать файл скриптом.
4. Строка обрезана — `vmlogs-cli get <stream_id>/<time>` из маркера.
5. Пусто или ошибка — таблица «Если не получилось».

`<фильтр>` начинай с namespace и контейнера: `kubernetes.pod_namespace:=<ns>
kubernetes.container_name:=<контейнер>`. Какой namespace у проекта — в его `CLAUDE.md`.
Если сборщик пишет поля иначе (`k8s.namespace`, `k8s.container_name`) — посмотри
`vmlogs-cli fields '*' --since 15m`.

## Окно времени

`--since 1h` (по умолчанию), `30m`, `6h`, `2d`, `1w`. Точное окно — `--start` и `--end`
(длительность или RFC3339 с зоной: `2026-04-19T10:30:00Z`). Можно и в самом запросе:
`_time:[2026-04-19T10:30:00Z, 2026-04-19T11:00:00Z]`.

## LogsQL — шпаргалка

| Нужно | Запрос |
|---|---|
| Точное значение поля | `kubernetes.container_name:=api` |
| Слово в сообщении | `error` — только **целое слово** |
| Начало слова | `timeout*` |
| Подстрока | `~"bulk_oper"` |
| Фраза | `"connection refused"` |
| Исключить | `-"health check"`, `-kubernetes.container_name:=sidecar` |
| Регулярка по полю | `kubernetes.pod_name:~"api-.*"` |
| Сравнение чисел | `status:>=500`, `duration_ms:>1000` |
| Посчитать по полю | `\| stats by (level) count() c` |
| По времени | `\| stats by (_time:5m) count() c` |
| Самые частые сообщения | `\| stats by (_msg) count() c \| sort by (c) desc \| limit 10` |
| Оставить поля | `\| fields _time, kubernetes.pod_name, _msg` |

Документация языка: https://docs.victoriametrics.com/victorialogs/logsql/

## Какие поля есть

```bash
vmlogs-cli fields '<фильтр>' --since 1h          # имена полей с числом строк
vmlogs-cli values '<фильтр>' level --since 1h    # значения поля с числом строк
```

Служебные поля (метки и аннотации пода, `_stream`, ip, нода …) скрыты; `--all-fields`
показывает всё.

## Вывод

`short` (по умолчанию): `<время> <контейнер> <УРОВЕНЬ> <сообщение>  k=v …`, записи по
возрастанию времени, переводы строк — `⏎`. Строки `| stats` — `k=v`. `-o json` — JSONL в
порядке VictoriaLogs (от новых к старым).

Маркеры:

- `… [truncated: N/M chars, get <stream_id>/<time>]` — строка обрезана до `--width` (1000
  символов). Полная запись: `vmlogs-cli get <stream_id>/<time>`. Формат маркера — контракт,
  не перефразируй его в скриптах.
- `[показаны последние N строк окна — есть ещё …]` — вернулись не все записи: VictoriaLogs
  отдаёт последние N. Сузь фильтр или посчитай через `| stats`.
- `[0 строк …]` — по фильтру ничего нет: см. таблицу ниже.

## Если не получилось

| Признак | Причина | Действие |
|---|---|---|
| `0 строк`, хотя событие было | Слово ищется целиком: `bulk` не найдёт `bulk_operations` | `bulk*` или `~"bulk"` |
| `0 строк` по сервису вообще | Не то окно, не тот namespace или другие имена полей | `--since` шире; `vmlogs-cli fields '*'` |
| `VictoriaLogs не принял запрос: cannot parse …` | Синтаксис LogsQL | Исправить место из `context:` |
| `нет входа …` / `Сессия Grafana не продлевается` | Транспорт grafana, сессия истекла | Попроси пользователя выполнить `vmlogs-cli login` (может открыться окно браузера для SSO) и повтори |
| `отвечает 302 на …` | Grafana просит вход или переехала | `vmlogs-cli login`; если хост другой — поправить профиль |
| `ssh <host>: …` | Нет доступа по ssh | Проверить `ssh <host> true` |
| `kubectl: …` | kubeconfig, контекст или права | `kubectl config current-context`, профиль |
| `не ответил … VPN` | Нет сети до сервиса | VPN, адрес в профиле |
| `нет профиля` | Профиль не создан | `README.md`, раздел «Профили» |
````

````markdown
## Профили

Профиль — env-файл `KEY=VALUE` без секретов. Первый найденный побеждает: `--env <файл>`,
`$VMLOGS_ENV`, `.vmlogs-cli/env` вверх от текущего каталога, `~/.config/vmlogs-cli/env`.
Удобно держать профиль по умолчанию в `~/.config/vmlogs-cli/env`, а профиль другого окружения —
в `.vmlogs-cli/env` общего каталога его проектов.

Напрямую (port-forward, сервис в кластере, открытый адрес):

```bash
VMLOGS_TRANSPORT=direct
VMLOGS_URL=http://localhost:9428
```

Через `kubectl` — прокси сервиса в API Kubernetes:

```bash
VMLOGS_TRANSPORT=kubectl
VMLOGS_KUBE_SERVICE=logging/victorialogs:9428   # <namespace>/<service>:<port>
VMLOGS_KUBECONFIG=~/.kube/config                # необязательно
VMLOGS_KUBE_CONTEXT=prod                        # необязательно
```

Через `kubectl` на сервере по ssh — когда API кластера доступен только оттуда (туннель не нужен):

```bash
VMLOGS_TRANSPORT=kubectl
VMLOGS_SSH_HOST=myserver                        # хост или алиас из ~/.ssh/config
VMLOGS_KUBE_SERVICE=logging/victorialogs:9428
```

`ssh` запускается с `BatchMode=yes`: вход по ключу должен работать без вопросов.

Через Grafana с SSO:

```bash
VMLOGS_TRANSPORT=grafana
VMLOGS_GRAFANA_URL=https://grafana.example.com
VMLOGS_DATASOURCE=VictoriaLogs                  # имя или uid; флаг --ds перебивает
```

Вывод настраивается в любом профиле:

vmlogs-cli login
```

1. Сохранённая cookie жива или продлевается ротацией токена — браузер не нужен.
2. Иначе [`playwright-cli`](https://www.npmjs.com/package/@playwright/cli) открывает браузер
   без окна с постоянным профилем `~/.config/vmlogs-cli/chrome-profile`: если SSO-сессия в нём
   жива, вход проходит молча.
3. Иначе открывается окно, вход проходит человек (до 5 минут).

Cookie хранится в `~/.config/vmlogs-cli/cookies/<хост>` с правами 600, одна на хост Grafana.
Когда запрос получает 401, `vmlogs-cli` один раз продлевает сессию без браузера и повторяет
запрос. Установить `playwright-cli`:
`npm install -g @playwright/cli && playwright-cli install-browser`.

## Команды

```bash
vmlogs-cli check                                          # профиль, транспорт, записи за 5 минут
vmlogs-cli query '<logsql>' [--since 1h] [--limit 50]     # строки или результат | stats
vmlogs-cli query '<logsql>' -o json                       # JSONL
vmlogs-cli query '<logsql>' --limit 5000 --out rows.jsonl # выгрузка в файл
vmlogs-cli fields '<logsql>'                              # имена полей с числом строк
vmlogs-cli values '<logsql>' <поле>                       # значения поля с числом строк
vmlogs-cli get <stream_id>/<time>                         # запись целиком по маркеру обрезки
vmlogs-cli datasources                                    # датасорсы логов в Grafana
```

Окно: `--since 15m|6h|2d` или `--start`/`--end` (длительность или RFC3339). Остальное —
`vmlogs-cli <команда> --help`.
````
